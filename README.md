# Power Query BI Project

This repository contains a Power BI project that demonstrates data transformation and cleaning using *Power Query*. The .pbix file includes real-world use cases showing how to prepare data efficiently before building interactive dashboards.

## Project Highlights

- Applied Power Query transformations to clean and shape raw data
- Created relationships between tables for a connected data model
- Demonstrated the ETL (Extract, Transform, Load) process in Power BI
- Set up queries for easier data refresh and automation
- Built foundational visuals using cleaned data

## File Included

- Power Query bi.pbix: Main Power BI project file

## Tools Used

- Power BI Desktop
- Power Query Editor
- Basic DAX formulas 

## How to Open

1. Download or clone the repository
2. Open Power Query bi.pbix in Power BI Desktop
3. Navigate to the *Power Query Editor* to view the transformations
